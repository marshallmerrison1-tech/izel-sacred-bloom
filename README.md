# İzel's Sacred Bloom — interactive baptism invitation

## Before publishing
1. **Confirm the date**. The website currently uses **2 January 2027** as a PROVISIONAL date because the earlier supplied year (2026) has already passed. In `index.html`, find `const EVENT={year:2027,...}` and correct the year if needed. Ceremony is 4 PM at St. Mary’s Latin Catholic Church, Pongumoodu; reception and dinner start at 5:30 PM at The South Park, Palayam, Kerala local time.
2. Add your chosen baby photograph as `assets/izel-photo.jpg` (optional; a placeholder is shown until then).
3. Add an MP3 file you have permission to publish as `assets/christian-piano.mp3` (optional; the music button will not play until you add one). Browsers may block autoplay until the user taps the invitation.
4. Confirm venue names and times before sharing. Map links open searches for each venue.

## Publish on GitHub Pages (no coding setup required)
1. Sign in to github.com and create a **public** repository called `izel-sacred-bloom`.
2. Open the repository, choose **Add file → Upload files**, and upload `index.html` and the `assets` folder contents with their paths preserved. An easy alternative is to upload the files individually using GitHub's web interface and create the `assets` folder via filenames such as `assets/izel-photo.jpg`.
3. Commit changes.
4. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Select `main` and `/(root)` and click **Save**.
5. Your website URL will be `https://YOUR-USERNAME.github.io/izel-sacred-bloom/`.
6. Open on mobile and test the envelope, music, photo, directions, countdown and share button.

The invitation is public to anyone with the link. Avoid publishing sensitive information. There is no RSVP data collection or server-side storage.
